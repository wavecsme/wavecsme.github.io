G Ads MCP Privacy Policy

Last updated: 20 November 2026

What this app is

G Ads MCP is a personal tool used only by its owner. It connects to the Google Ads API so the owner can view reports and manage their own Google Ads campaigns.

Data we access

With the owner's explicit consent through Google OAuth, the app accesses Google Ads account data the owner is already authorized to see, such as campaigns, ad groups, keywords, ads, and performance metrics.

How data is used

This data is used only to perform the actions the owner requests, such as generating reports or editing campaigns. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

OAuth credentials and any retrieved data are stored only on the owner's own computer. We do not sell, share, or transfer this data to any third party. The app does not operate a server that collects data from other people.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
